Detailed Description

Shared C2P-ARQ protocol definitions for SH2SC-EDT (Transmitter Node A).

Part of the SH2SC-EDT project. Implements the C2P-ARQ protocol. Contains the Pre-Shared Key, frame flag constants, packed packet structs (HelloPacket, DataPacket), ARQ timing constants, and UART configuration shared by both Transmitter and Receiver nodes. Included from transmitter.h; do NOT include directly from .ino.
